Các route dưới đây sử dụng API client A0, base `/api`; không tự ghép thêm `/api` vào route controller khác. UUID BookingPassenger khác User/Passenger ID. Query key được prefix API URL, owner, signedInAt bởi passengerKey; C thêm booking/BookingPassenger/cruise/itinerary/target phù hợp.
